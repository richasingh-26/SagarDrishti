# SagarDrishti

Maritime Oil Spill Forensics System — SIH 2026

## Features
- 🛰️ Sentinel-1 SAR oil spill detection (U-Net++, 99% accuracy)
- 🚢 AIS vessel tracking + Isolation Forest anomaly detection
- ⭐ Virtual Spill Simulation (physics-based attribution)
- 📊 Real-time dashboard

## Tech Stack
- **Backend:** FastAPI + PyTorch
- **Data:** Sentinel-1, Copernicus Marine, AISStream
